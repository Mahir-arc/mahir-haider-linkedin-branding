# MAHIR HAIDER — Client Demo Studio

A collection of five responsive, static website concept experiences built to demonstrate strategy, visual direction and conversion-minded web design.

## Preview locally
Open `index.html` in a browser. Each concept is a standalone HTML page:
- `law.html` — boutique legal practice
- `dental.html` — dental and healthcare
- `real-estate.html` — real estate advisory
- `saas.html` — B2B software
- `hospitality.html` — boutique hospitality

## Publish as a separate static site
Set the hosting provider's publish directory to `demo-studio`. No build command is required.

## Important
These are original demonstration concepts with fictional brand names and sample content. They are not client commissions, endorsements, or representations of real businesses. Replace all sample content and imagery with approved assets before presenting a concept as a paid client deliverable.
